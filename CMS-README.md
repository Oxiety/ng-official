# Админ-панель

Адрес: `https://northling.space/admin/` (старый адрес `/admin/panel` перенаправляет сюда).

Это наша самописная страница без сторонних сервисов и серверов (Decap CMS полностью удалён). Она читает и пишет файлы прямо в GitHub-репозиторий через GitHub API, а Vercel сам пересобирает сайт.

**Первый вход.** Укажи репозиторий (`owner/repo`), ветку (`main`) и токен GitHub. Токен делается один раз: github.com/settings/personal-access-tokens/new → выбрать репозиторий сайта → Permissions → Contents: Read and write. Токен хранится только в браузере.

**Что умеет.**
- Арты и Фотки: список работ, у каждой название, описание, дата, место, подпись и кадрирование в рамке (отдельно для компьютера и телефона, только с компьютера).
- Тексты и обложки: заголовки, вводные тексты, обложки разделов (с кадрированием), бегущие строки (слова через `|`).
- Oasis: карточки, песни, концерты, альбомы, B-Sides, «Алмазики».
- Музыка: библиотека плеера. Исполнитель → альбомы → треки (название и ссылка на файл, например с jukehost). Треки можно добавлять списком: кнопка «Добавить списком», по строке `Название | ссылка`. Также тут задаётся Telegram, куда приходят предложения треков. Сами файлы в репозиторий не загружаются, только ссылки.
- Интерактивчик: все тексты, числа и правила казино, символы слотов, звания, лента выигрышей, реклама, сообщения в играх.
- Аниме: тексты (включая японские), цитаты, картинка кадра, список тайтлов с жанрами.
- Терминал: тексты блока на webdev, ответы команд, файлы, предсказания и свои команды.
- Обо мне: вся страница about.html (шапка, фото, рассказ, факты, навыки, опыт, проекты, контакты).
- Деловой режим: переключатель в «Тексты и обложки», прячет фурри и страницу «Аниме».
- Списки (треки, альбомы, тайтлы, цитаты…) переставляются перетаскиванием за ручку ⠿ слева.
- Медиа: загрузка картинок. Большие фото автоматически уменьшаются до 2400px по длинной стороне.
- Все изменения уходят в репозиторий одним коммитом по кнопке «Сохранить на сайт».

**Как добавить новое поле.** Схема полей зашита прямо в `admin/index.html` (константа `SCHEMA`). Добавил поле в JSON-данные и на страницу: добавь его и в `SCHEMA`. Виджеты: `string`, `text`, `select`, `list`, `image`, `fit` (кадрирование).

**Где лежат данные.** `data/arts.json`, `data/photos.json`, `data/site.json`, `data/oasis.json`, `data/music.json`, `data/arcade.json`, `data/anime.json`, `data/terminal.json`. Картинки: `img/uploads/`.
